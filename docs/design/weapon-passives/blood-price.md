## 실제 피해 누적

`UMVStatComponent::OnDamageApplied`의 실제 체력 감소량 사용
피격 당시 최대 체력에 대한 감소 비율을 패시브 행동 객체에 누적

```text
누적 비율 += 실제 체력 감소량 / 피격 당시 최대 체력
발동 횟수 = 누적 비율에 들어 있는 0.05 단위의 개수
남은 누적 비율 = 누적 비율 - 발동 횟수 × 0.05
```

- 방어력·불굴의 의지 등 모든 피해 보정 후 실제 줄어든 체력만 집계
- 한 피격으로 여러 기준을 넘으면 그만큼 발동, 5% 미만의 나머지는 보관
- 최근 피해 표시·그로기용 `AccumulatedRecentDamage`는 자체 초기화 시간이 있으므로 사용하지 않음
- 최대 체력은 피해 시점의 값으로 판단; 필요한 사건 데이터는 구현 시 원본 코드에서 전달 시점 확인
- 수치가 정확히 5% 경계에 도달했을 때 부동소수점 오차로 발동을 놓치지 않도록 확인

| 항목 | 기준 | 구분 |
|---|---|---|
| 기본 조건 | 실제 피해 누적이 최대 체력의 5%에 도달할 때마다 환원 | 기획 |
| 피해 종류 | 체력을 줄이는 일반·스킬·직접·지속 피해 포함 | 제안 |
| 제외 | 체력 비용 지불, 체력 직접 설정, 체력 피해 없는 방어 | 설계 |
| 회복 | 이미 쌓인 비율 유지 | 제안 |
| 최대 체력 변경 | 이전 누적 비율 유지, 다음 피해부터 새 최대 체력 사용 | 제안 |
| 사망·패시브 해제 | 누적 초기화, 사망한 피격에서는 환원하지 않음 | 제안 |
| 환원할 쿨타임 없음 | 기준에 도달한 누적은 소비, 미래 사용을 위한 환원 저장 없음 | 제안 |

## 쿨타임 환원안

현재 무기의 대기 중인 스킬 주 쿨타임을 남은 시간 기준으로 10%씩 줄이는 안
원래 쿨타임의 10%를 고정 차감하는 방식과 다르므로 구현 시작 때 기준 확정

```text
새 남은 시간 = 기존 남은 시간 × 0.9 ^ 발동 횟수
```

| 예시 | 결과 |
|---|---|
| 최대 체력 1,000에서 실제 체력 120 감소 | 2회 환원, 2% 누적 잔여 |
| 남은 쿨타임 10초에서 한 번 환원 | 9초 |
| 남은 쿨타임 10초에서 같은 순간 두 번 환원 | 8.1초 |

- 연계 단계 사이 대기시간과 연계 입력 제한 시간은 유지하는 안
- R 스킬의 별도 충전 게이지는 환원하지 않음
- 준비된 스킬에는 추가 혜택을 저장하지 않고 음수 쿨타임을 만들지 않음
- 실행 중 아직 시작되지 않은 쿨타임에 대한 예약 환원은 이 패시브의 기본안에서 제외
- 이미 진행 중인 쿨타임의 감소가 이후 종료 처리에서 덮어써지지 않도록 구현

## 공통 쿨타임 처리 책임

| 구성 | 책임 |
|---|---|
| 피 흘린 만큼.. 행동 | 실제 피해 비율·발동 횟수 계산, 감소 요청 |
| `UMVCombatComponent` | 현재 무기의 대상 스킬 확인과 공통 감소 기능 제공 |
| `FMVSkillEntry` | 해당 스킬의 실제 남은 쿨타임과 종료 처리에 필요한 보정 상태 관리 |
| 스킬 실행 검사·UI | 동일한 남은 시간 계산을 사용 |

- `LastUsedTime`을 패시브가 직접 수정하지 않고 전투 영역의 공통 기능으로 요청
- 기존 미사용 상태 표식인 0과 실제 시각을 혼동하지 않도록 시간 계산 확인
- 스킬 종료 시각을 다시 기록하는 `StartPostAbilityResetWindow`에서도 이미 반영한 감소 보존
- 다음 포식자의 순환이 같은 쿨타임 조회·갱신 계약을 사용하도록 분리; 전용 누적값은 공통 구조에 넣지 않음
- 장착 해제는 남은 피해 누적만 정리, 이미 줄어든 쿨타임을 되돌리지 않음

## 자산과 생명주기

- `DA_Passive_BloodPrice`, `UMVBloodPricePassiveBehavior` — 가칭
- 본체 `Infinite`·`NoStack`·`OnePerSource`, 별도 중첩 상태 효과 불필요
- 양손 방패 세트에 본체 추가, 현재 무기로 우선 시험
- 적용 시 실제 피해·사망 사건 구독, 제거 시 자기 구독과 남은 누적 정리
- 이미 사망했거나 최대 체력이 유효하지 않은 상태에서는 누적·환원 제외
- 신규 GameplayTag는 프로젝트의 `MVGameplayTags.h`·`.cpp`에서 선언·정의

## 구현 단계

| 단계 | 작업 | 확인 기준 |
|---:|---|---|
| 1 | 환원 기준 확정, 본체와 실제 피해 비율 누적 구현 | 작은 피해의 합산·한 번의 큰 피해·잔여값 정확성 |
| 2 | 전투 영역의 주 쿨타임 조회·감소 기능 구현 | 10→9초, 두 번이면 8.1초; 실행 검사와 UI 일치 |
| 3 | 발동 횟수와 쿨타임 감소 연결 | 대상 스킬만 감소, 연계 입력 시간·R 게이지 유지 |
| 4 | 피해 종류·회복·최대 체력 변경·종료 시각 시험, 임시 로그 정리 | 중복·초기화 누락·감소 취소 없음, 사용자 실행 확인 |

## 완료 기준

- 5% 미만·정확히 5%·초과·한 번에 여러 배수의 피해 확인
- 불굴의 의지와 함께 적용할 때 감소된 실제 피해를 기준으로 집계
- 지속 피해 포함, 체력 비용·직접 설정 제외 확인
- 준비된 스킬에 환원이 저장되지 않고 사용 중 스킬과 대기 중 스킬을 구분
- 사망·해제·재장착 시 잔여 누적 초기화, 이미 환원한 시간은 보존
- 임시 로그 접두어 제안: `BloodPriceTrace`; 실제 피해·최대 체력·잔여 비율·발동 횟수·쿨타임 전후 기록
- 완료 뒤 실제 동작을 무기 패시브 위키에 반영하고 다음 포식자의 순환 안내
