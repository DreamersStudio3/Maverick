# Async Loading Screen 영상 미출력 수정

- 목표: 최초 게임 로딩에서 소리만 출력되고 영상이 보이지 않는 원인 확정 및 수정
- 상태: DreamersLog 교체 후 시작 화면 배경 알파 1 재저장 확인, 알파 0 재적용, 실제 재생 검증 대기
- 결정: 안내 문구용 위젯 겹침 유지, 영화를 가리던 시작 화면 배경 알파만 0으로 변경
- 위키 검토: 변경 불필요: 프로젝트 구조·장기 운영 계약 변화 없는 플러그인 설정 수정
- 검증: 설정·영상 경로·H.264/AAC 트랙·플러그인 렌더링 코드·설정 차이 정적 검증 통과, 기존 Unreal Editor 프로세스 보호를 위해 재시작 런타임 검증 미실행
