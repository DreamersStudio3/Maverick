- 갱신일: 2026-10-30
- 상태: 거인의 강인함 선택 성공, 수치 검증 사용자 요청으로 보류; 약점 포착 기본 공격·체력 조건·해제·재선택 확인, 임시 로그 제거 후 사용자 재빌드 대기; 철벽 미착수
- 결정: 거인의 강인함 → 약점 포착 → 철벽 순서, 승인된 권장안으로 진행하고 추후 피드백 반영
- 협업: 에이전트가 C++ 코드 수정과 작업 내용 보고, 사용자가 Editor의 Blueprint·데이터 자산 연결 및 빌드 수행
- 위키 검토: 갱신: `docs/wiki/Features/Combat/Weapon-Passives/document.md`; 거인의 강인함 사용자 빌드·Editor 실행 검증 후 실제 동작 반영
- 검증: Windows/Codex에서 임시 로그 제거 후 확률 보정·구독 해제 코드 보존 정적 확인과 `git diff --check` 통과; 사용자 로그에서 MaxHP 4000의 기준 1200에 대해 HP 1403.50은 확률 0→0, HP 1034.00은 0→0.20 확인, 해제·재선택·중복 없음은 사용자 보고; 로그 제거 후 재빌드·실제 치명타·정확히 30% 경계·투사체는 미검증, 거인의 강인함 수치도 보류, 빌드는 사용자 담당

## 거인의 강인함 현재 상태

- C++: 네이티브 상태 효과 태그, 본체 행동, 효과별 강인도 보정·해제, 받는 체력 피해 ×1.15 작성
- 강인도: 남은 일반 강인도·공격 중 추가 강인도 환산, 보스 고정 소진 구간의 저장된 일반 상태만 환산
- Editor: 사용자가 현재 한손 시험 무기에 본체·공용 Ability·행·후보를 연결하고 `SelectPassive = true` 확인
- 보류: 강인도 30%·받는 피해 15%, 해제·특수 구간의 실제 수치 확인은 사용자 요청으로 연기
- 수치 검증 전 거인의 강인함 동작 검증 완료로 기록하지 않음

## 약점 포착 현재 단계

- 1단계: 유효 공격의 치명타 판정 전에 타격 문맥과 확률을 넘기는 공통 사건 추가; 사용자 빌드·기본 적중 확인
- 기존 공격 피해 보정과 같은 공격 출처·생존 주기·무기 검사 재사용
- 2단계: 대상의 피해 전 HP 30% 이하 검사, 이번 타격의 치명타 확률 +0.20, 효과별 구독 해제 C++ 작성
- Editor: 사용자가 본체 상태 효과·공용 Ability 자식·패시브 행·현재 한손 무기 후보 연결 후 실행 로그 확인
- 정리: 적용·해제·확률 확인용 `WeakPointTrace` 로그 제거; 사용자 재빌드 대기
- 추가 검증: 실제 치명타 발생, 정확히 30% 경계와 투사체·생존 주기 경계는 아직 증거 없음

## 진행 기준

- 약점 포착은 단계별 빌드·실행 확인 후 다음 코드 변경 안내; 거인의 강인함 수치 검증은 보류로 추적
- 문서 저장과 실제 구현·실행 검증 완료를 구분
- 변경 안내 직전에 현재 소스 재확인, 이전 조사 시점의 줄 번호를 그대로 사용하지 않음
- 빌드는 사용자가 수행; 커밋·원격 반영·노션 기록은 별도 요청에서 진행
- 세 패시브 구현·검증과 위키 인계 완료 후 이 단기 작업 파일 정리
