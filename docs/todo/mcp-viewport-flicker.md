# MCP 연결 시 뷰포트 깜빡임 조사

- 목표: MCP 연결과 검은 화면 발생 사이의 실행 경로 확인
- 상태: 기존 로그 확인 완료, 깜빡임 재현 시점과 명령 호출의 대조 필요
- 결정: 원인 확인 전 렌더링 설정 변경 보류
- 위키 검토: 변경 불필요: 진단 단계이며 확정된 구현 변경 없음
- 검증: Agent 의존성 Graphify 0.9.38 확인, Graphify 질의는 Ensure-GraphifyReady.ps1의 HostName 매개변수 오류로 실패
- 관측: 기존 로그에서 PIE 실행 중 MCP 조회 및 속성 변경 호출 확인, 연결 자체와 깜빡임의 인과관계 미확정
