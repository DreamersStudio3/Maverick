# 작업 기록 규칙

`docs/todo/`는 진행 중인 작업의 짧은 인수인계 메모만 둔다. 장기 설계나 완료 이력을 쌓는 폴더가 아니다.

1. 작업을 시작할 때 `docs/todo/<task>.md` 하나를 만들고 목표, 현재 상태, 중요한 결정, 검증 결과만 적는다.
2. 범위나 판단이 바뀌거나 검증이 끝났을 때만 갱신한다. 프롬프트 원문, 긴 코드 조사, 일반적인 Git 절차는 복제하지 않는다.
3. 작업이 끝나면 오래 남아야 할 책임·설계는 `docs/wiki/`에, 타입 가까이 있어야 할 계약은 C++ 헤더에 반영한다.
4. 완료 파일은 삭제한다. 나중에 이력을 찾는 데 실제 도움이 되는 결과만 [Completed-Work.md](Completed-Work.md)에 한두 문장으로 합친다.

작업 파일의 최소 형식은 다음과 같다.

```markdown
# 작업명

- 목표:
- 상태:
- 결정:
- 검증:
```

이 폴더는 미완성 가설이 위키에 섞이지 않도록 Graphify 입력과 pre-push 지식 원본 계산에서 제외한다.
