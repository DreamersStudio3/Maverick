# 실험동 회랑형 플레이 검증

- 목표: 6층 회랑형 동선의 실제 조작 완주 및 전투 체감 확인
- 상태: 방 20개·층별 회전·4층 단실 분기·층고 8m·공용 계단 10개·E 메뉴·문 상승 연출 구현
- 결정: 1~5층 계단 B 상승, 6층 종료; 계단 A는 잔해로 영구 차단; 보스 사망 대신 체크포인트 메뉴 버튼 사용
- 위키 검토: 갱신: docs/wiki/Features/Level-Design/Experiment-Blockout/document.md, Blockout-Assets/document.md
- 검증: 전용 BP/위젯 경고 포함 컴파일 통과; PIE 버튼 활성화로 6개 문 독립 해금 확인; 계단 175지점·연결부 475지점·최종 통과 선분 54개 검사 통과
- 추가 검증: 1층·6층 실제 E 메뉴 및 처치 연출 확인, 8m 계단 바닥·상층 연결부 280지점 통과
- 변주 검증: 회랑 2,160·계단 250·머리 여유 250·연결 94·차단 72지점 통과, 회전한 2층 실제 E와 문 연출 확인
- 후속 검증: 실제 캡슐 가장자리 침하 재현·수정, 7개 위치 지지 및 이동 145프레임 Z 유지, 상승 계단 5개 상부 벽·천장 폐쇄
- 남은 검증: 1~6층 직접 완주, 회피·점프 우회, 실제 보스·락온·낙사 복귀
- 범위: 실제 보스·영속 저장 미구현, 승강 타워 레벨 변경 없음
