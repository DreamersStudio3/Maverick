# 원거리 발사체와 자동 유도 대상 선택

## 핵심

- 기존 공격 애니메이션의 Ability 구간에서 원거리 Ability가 발사체를 생성

## 변경

- 발사 시 공격 번호와 무기 정보를 보관해 Ability 종료 후 적중도 원래 공격에 연결
- 발사체 Base가 자기 자신·아군 제외, 중복 적중, 관통, 지형 충돌, 종료 처리
- 전투 컴포넌트가 공격별 발사체를 추적하고 공격 기회와 발사체가 모두 끝난 뒤 빗나감 확정
- `ProvidedOnly`는 기존 지정 경로 유지; 자동 모드는 명시 대상, 현재 대상, 주변 적 순서로 발사 시 한 번 선택

## 기준

- 주변 후보는 생존·적대·무적 여부와 설정된 거리·정면·가림 조건으로 선별
- 비행 중 대상 재선택 없음; 관통탄이 유도 대상에 맞으면 유도만 해제하고 현재 속도로 진행
- 사용자 Windows Editor에서 자동화 시험 3건 통과, 다수 적 실제 플레이 확인; 에이전트 직접 실행 없음
