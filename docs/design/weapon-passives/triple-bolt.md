## 동작 설계

장착 중 유지되는 패시브 본체가 대상 공격의 명중을 받고, 적에게 별도 3타 표식을 적용
대상별·시전자별로 중첩을 쌓고 3타 추가 피해 후 표식 소비

| 항목 | 기준 | 구분 |
|---|---|---|
| 대상 공격 | 기본 공격·주력 사격; 현재 무기 평타로 우선 시험 | 기획·사용자 결정; 주력 사격과 투사체는 무기 제작 후 연결 |
| 발동 횟수 | 3회 유효 명중마다 추가 피해 | 기획 |
| 집계 단위 | 대상별·시전자별 독립 표식 | 기존 3타 구조를 재사용하는 제안 |
| 표식 유지 | 마지막 대상 명중부터 5초, 명중 시 갱신 | 제안 |
| 자신의 피격·빗나감 | 표식의 남은 시간 유지 | 제안 |
| 시전자·대상 사망, 패시브 해제 | 자신이 만든 표식 제거 | 설계 |
| 추가 피해 | 대상 최대 체력의 8% | 사용자 확정 |

예시: A에게 두 번, B에게 한 번 명중하면 A는 2중첩, B는 1중첩
이후 A를 맞히면 A에게 추가 피해를 적용하고 A의 표식만 소비

## 기존 3타 효과의 재사용

- 기존 `UMVStackMaxHealthDamageBehavior`의 임계 중첩 확인·후속 처리·효과 소비 흐름 참고
- 대상 최대 체력 비례 피해를 지원하는 기존 행동을 재사용하고, 세 번째 명중에 0.08을 적용
- 0.08은 기존 행동의 기본값과 우연히 같지만, 이번에는 사용자가 확정한 트리플 볼트 수치로 명시적으로 설정
- 기존 3타 표식과 다른 Definition·GameplayTag를 사용해 중첩 합산 방지
- 같은 트리플 볼트 효과를 공격 행과 패시브 본체에서 동시에 적용하지 않음

## 명중과 추가 피해 순서

1. 원래 공격의 출처·대상·종류를 확인하고 이번 유효 명중을 식별
2. 원래 타격의 피해 전달이 완료된 지점에서 표식을 적용하거나 발동 처리
3. 세 번째 명중이면 대상 생존 여부와 발동 유효성을 다시 확인
4. 추가 피해를 한 번 요청하고 표식 소비
5. 추가 피해는 직접 피해 출처와 별도 공격 번호 규칙을 사용해 추가 명중으로 재집계하지 않음

- 현재 `OnValidatedAttackHit`은 피해자의 체력 차감 전에 발생하므로 그 구독만으로 위 순서가 보장되지는 않음
- 구현 때 `UMVHitResolverSubsystem`의 타격 처리 완료 지점과 연결; 단순 시간 지연으로 순서를 추정하지 않음
- 추가 피해는 `DirectDamage` 출처와 `INDEX_NONE` 공격 번호로 전달하고, 표식 적용은 `AttackCollision`만 받아 재집계를 막음
- 원래 피해로 대상이 사망했다면 추가 피해를 만들지 않고 해당 표식 참조 정리
- 추가 피해는 기존 직접 피해·피해자 보정 경로 사용; 별도 경직·강인도·그로기 피해는 부여하지 않는 안
- 실제 투사체 연결 시 발사 시점 실행 정보 보관; 현재 Ability가 종료된 뒤 도착한 공격도 원래 출처로 확인

## 자산과 수명 관리

| 구성 | 설정 |
|---|---|
| `DA_Passive_TripleBolt` — 가칭 | `Infinite`·`NoStack`·`OnePerSource`, 대상 명중을 표식 적용으로 연결 |
| `DA_Effect_TripleBoltMark` — 가칭 | `Timed`·`AddStack`·`OnePerSource`·`RefreshDuration`, 최대 3 |
| 표식 행동 | 기존 `UMVStackMaxHealthDamageBehavior` 재사용; 3중첩에서 대상 최대 체력의 8% 추가 피해 |
| 무기 세트 | 아웃사이더 스텝과 같은 석궁·활용 세트에 본체 추가 |

- 본체는 표식을 만든 대상 컴포넌트를 약한 참조로 보관하고, 해제 시 정의·시전자로 현재 핸들을 찾아 제거
- 대상 소멸·표식 소비·만료 시 무효 참조 정리, 해제 시 자신의 남은 표식만 제거
- 현재 무기 평타로 먼저 시험; 주력 사격 판별은 실제 석궁·활과 투사체 제작 후 공격 종류·실행 정보로 전달
- 신규 GameplayTag는 프로젝트의 `MVGameplayTags.h`·`.cpp`에서 선언·정의

## 구현 단계

| 단계 | 작업 | 확인 기준 |
|---:|---|---|
| 1 | 대상 공격·피해 기준·유지시간 확정, 전용 표식·본체 구성 | 기존 3타 효과와 별도 집계 |
| 2-가 | 타격 처리 완료 사건을 전투 컴포넌트에 전달 | 원래 체력 차감 뒤에만 사건 발생, 직접 피해 제외 |
| 2-나 | 완료 사건에서 대상별 표식 적용 | 1·2타 중첩, 대상·시전자 변경 시 독립 유지 |
| 3 | 기존 표식 행동의 3타 추가 피해·표식 소비와 재진입 방지 검증 | 세 번째 타격마다 한 번, 다음 명중은 새 1중첩 |
| 4 | 만료·장착 해제·대상 사망·다단 타격 시험, 임시 로그 정리 | 누락·중복 피해와 남은 표식 없음, 사용자 실행 확인 |

## 완료 기준

- 추가 피해 기준과 수치를 문서에 확정한 뒤 실행 결과 비교
- 3·6·9번째 대상 명중에서 반복 발동, 다수 대상·시전자 분리 확인
- 기본 공격·주력 사격 포함과 다른 스킬·직접 피해·지속 피해 제외 확인
- 원래 타격으로 사망한 대상, 추가 피해로 사망한 대상 처리 확인
- 표식 만료·재장착·자신의 사망 이후 첫 타격은 1중첩부터 시작
- 임시 로그 접두어 제안: `TripleBoltTrace`; 대상·시전자·공격 번호·중첩·추가 피해·소비 사유 기록
- 완료 뒤 실제 동작을 무기 패시브 위키에 반영하고 다음 피 흘린 만큼.. 안내
- 원거리 무기와 투사체의 지연 명중 검증은 현재 시험 무기 확인과 구분

## 조사 근거와 검증 범위

- 현재 무기 평타 6회 실행 로그: 1·2타 표식 1·2중첩, 3타에서 2→0과 체력 320 감소, 4·5타 1·2중첩, 6타에서 다시 2→0과 체력 320 감소
- 같은 대상에 대한 3타 반복·소비는 확인; 대상 최대 체력이 4,000이고 별도 피해 보정이 없다면 320은 확정 비율 8%와 일치
- 사용자 실행 확인: 서로 다른 대상의 중첩 분리, 5초 만료, 빗나감 후 표식 유지가 정상 동작함; 이 세 시험의 개별 로그는 제공되지 않음
- 사용자 실행 확인: 장착 해제와 시전자 사망 시 표식 제거, 평타 외 스킬·직접 피해의 표식 제외가 정상 동작함; 개별 로그는 제공되지 않음
- 사용자 실행 확인: 대상 사망 직후 표식 제거와 사망 타격의 처리 순서가 정상 동작함; 개별 로그는 제공되지 않음
- 다른 시전자 분리와 다단 타격은 아직 확인되지 않음; 표식 만료 뒤 대상 사망 구독을 다음 유효 평타 또는 패시브 해제 때 정리하는 코드는 적용됐으나 개별 실행 로그는 제공되지 않음
