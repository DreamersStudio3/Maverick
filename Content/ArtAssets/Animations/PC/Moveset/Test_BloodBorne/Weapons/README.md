# Graceborne 0.2.5 무기 모션

엘든링 원본 플레이어 애니메이션 바인더 14개와 대조한 결과. 모드 장비의 공격 슬롯에서 실제로 참조하는 클립을 추적하고, 원본과 일치하는 모션 데이터 및 다른 ID로 복사된 동일 모션을 비교 대상에서 제외했다.

- 대상 경로 `/Game/ArtAssets/Animations/PC/Moveset/Test_BloodBorne/Weapons`
- 원본 스켈레톤 시퀀스 경로 `/Game/ArtAssets/Mannequins/Rigs/Test_BloodBorne/SourceAnimations/Weapons`
- 리타게터 `RTG_C0000_to_Manny`, 대상 메시 `SKM_Manny_Simple`
- Manny 타깃 포즈 `GroundedFeet`는 기존 `Default Pose`에서 양쪽 발목의 발끝 방향을 10° 올리고 골반을 1.5 cm 낮춘 포즈다. 두 포즈는 리타게터의 Target에서 전환해 비교할 수 있다.
- 61개 장비 항목, 2,187개 슬롯, 1,609개 원본 클립 ID, 동일 데이터를 통합한 고유 시퀀스 1,098개
- 무기 간 공유 시퀀스 393개는 `Shared`에 배치. 개별 무기에서 접근할 공유 시퀀스는 아래 CSV에서 무기명으로 필터링.

[무기별 전체 슬롯과 시퀀스 경로](Graceborne-025-Weapon-Motions.csv)

무기 시퀀스 이름은 `AS_GB_<폴더명>_<공격유형>` 형식이다. 같은 폴더와 유형에 고유 클립이 여러 개면 `_V01`부터 구분한다. `Shared`의 사용 무기와 원본 슬롯·클립 ID는 위 CSV에서 확인할 수 있다.

예를 들어 톱단창의 `a088_030010` 슬롯은 오른손 약공격 2타이며 `AS_GB_SawCleaver_AttackRightLight2`를 사용한다. Reikaze의 오른손 약공격 6타는 슬롯 `a628_030050`에서 클립 `a628_030010`을 재생한다.

## 에디터 검증

- Manny 시퀀스 1,098개와 C0000 원본 스켈레톤 시퀀스 1,098개를 저장하고 목록의 경로와 대조했다.
- 원본 HKX, 가져온 시퀀스, 리타겟 시퀀스의 키 개수가 클립별로 일치했다. 총 81,265키. 30fps 1,087개와 60fps 11개의 재생 길이와 대상 스켈레톤을 확인했다.
- 모든 클립의 시작·25%·50%·75%·끝에서 루트·골반·머리·양손·양발 포즈를 평가했다. 검증 범위는 캐릭터 스켈레톤의 움직임이다.
- 뒤꿈치 보정 후 1,098개 시퀀스의 스켈레톤·키 수·재생 길이를 다시 확인했다. 다섯 시점에서 골반·양쪽 발목·발볼은 새 리타겟 결과와, 루트·양손은 기존 시퀀스와 일치했다. 톱단창 오른손 약공격 5타 첫 프레임의 왼발 기울기(발목에서 발볼까지의 내리막 각도)는 38.9°에서 28.9°로 줄었다.

## 목록 읽는 법

- 각 행의 슬롯 수는 무기에서 참조한 동작 슬롯 수, 모션 수는 해당 무기의 중복 데이터를 통합한 수. 여러 무기가 같은 모션을 쓰므로 무기별 모션 수 합계에는 중복이 있다.
- CSV의 `TAE slot`은 장비에서 호출하는 슬롯, `Resolved HKX`는 참조를 따라간 실제 원본 클립. 마지막 열은 콘텐츠 브라우저의 Weapons 기준 상대 경로.
- 동작명은 슬롯 기준. `Both`는 한 무기를 양손으로 쥔 계열, `Dual`은 쌍수 계열. `Weapon skill` 뒤의 숫자는 전기 내부 슬롯 번호. 연출상 무기 형태와 입력 조작은 다를 수 있다.
- `new_slot`은 엘든링 원본에 같은 클립 ID가 없는 경우, `modified_slot`은 같은 ID에서 모션 데이터가 바뀐 경우. 제작자나 창작 출처는 파일 대조로 판별할 수 없다.
- 이름이 비어 있는 장비 3개는 `Unnamed`와 장비 ID로 표시. Coelshredder 전기 슬롯 `a911_040000`과 `a911_040005`는 동일 ID의 서로 다른 데이터가 모드 바인더와 DLC 바인더에 있어 보류.
- 엘든링 장비명이 남은 Marais Executioner's Sword는 모드가 기본 공격 카테고리를 25에서 40으로 바꿨다. 이 장비에 연결된 변경 모션 12개를 포함했다.
- 무기 설정이 그대로인 엘든링 장비에서만 추가로 연결되는 차이 33개는 모드 무기의 모션으로 확정할 수 없어 제외했다. 해당 클립의 접두사는 `a190` 8개, `a196` 8개, `a197` 7개, `a541` 6개, `a635` 2개, `a636` 1개, `a637` 1개다.
